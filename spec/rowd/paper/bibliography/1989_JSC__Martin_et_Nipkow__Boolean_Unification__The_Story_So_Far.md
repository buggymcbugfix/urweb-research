# Boolean Unification — The Story So Far

Ursula Martin and Tobias Nipkow. Journal of Symbolic Computation 7, 1989. No DOI printed. The PDF is a LaTeX
typesetting paginated 1–15 (same as the PDF pages, not the journal's); those pages are cited below.

**What it is.** A survey of unification in Boolean rings, which is unitary: an equation has no solution or a
single mgu. Any s = t becomes f(x) = 0 (p. 2–3); an mgu is a "reproductive solution", a vector of functions F
with f(F(x)) = 0 and F(s) = s for every solution s (p. 3), computed either by Boole's successive variable
elimination (Lemma 3.3, Theorem 3.4) or by Löwenheim's formula F(x) = x + f(x) ∗ (x + b) (Theorem 3.6) from a
particular solution b. Both rest on deciding t = 0 in the ring (§5) and on finding a particular solution (§6,
NP-complete), which Stone's representation (§4) reduces to m independent problems over the two-element ring 2,
m the number of atoms. Both cost O(m ∗ l ∗ 2^n) for l symbols and n variables, O(l ∗ 2^(k+n)) in the free
Boolean ring on k constants (§7). §8 translates the formulas to {0, complement, ∗, ∪}; §9 adds free function
symbols (atoms containing variables), which makes unification finitary.

**Why it matters for rowd.** The paper's Boolean rings have a unit: the definition in §2 (p. 1–2) has
"1 ∗ x = x", x̄ abbreviates x + 1, and the power-set example is P(S) for finite S with "1 is S". Our {Unit} rows
have no 1. Free of 1, so carrying over: the reduction of s = t to s + t = 0, the definition of reproductive
solution and the argument that it is an mgu (p. 3), and Löwenheim's formula (8), given a particular solution b.
Using 1: Lemma 3.3 and Theorem 3.4 substitute 1 for the eliminated variable and add 1 in (4); Theorem 4.4's
atoms and Lemma 4.5's 0-test multiply by (1 + w); §6.1's linear-time particular solution sets variables to 1;
§8 assumes the target signature is "as expressive as Σ", which {0, ∪, --, ∩} is not. Our observations, not the
paper's: the 1s of (2) and (4) cancel or distribute away ((h + 1) ∗ x1 = h ∗ x1 + x1), so Boole's method run as
polynomial arithmetic yields 1-free terms from 1-free f; (13) with x ∗ f̄(x) read as x -- f(x) is Löwenheim in
our operators, F(x) = (x -- f(x)) ∪ (b ∗ f(x)); and Theorem 3.2 (unproved in the paper) fails if "subalgebra
generated by the constants" is read as the subring they generate in our structure: for f(x) = x ∗ a + a (a ⊆ x)
that subring is {0, a}, where x ↦ a is reproductive, but over finite sets the mgu is x ↦ x ∪ a; what is missing
is Theorem 4.4's atom c̄1 ⋯ c̄n outside every constant, not a finite set. §9 is the nearest the paper comes to set
elements that are not constants (terms with variables; in Ur, name variables): there unification is finitary.

## Pointers

- §2 "Boolean Rings", p. 1–2 — definition with 0 and 1, x̄ := x + 1, the rewrite system R (Hsiang & Dershowitz
  1983) deciding equality in free Boolean rings, P(S) under symmetric difference and intersection, "1 is S".
- §3, p. 2–3 — s = t iff s + t = 0, so unification is matching against 0, equation (1). Lemma 3.1, Theorem 3.2:
  (1) is solvable in B iff in the finite subalgebra D generated by the constants of f, and "any mgu of (1) with
  respect to D is also an mgu with respect to B". Stated without proof; D is a subalgebra, so contains 1.
- Solution terminology (after Rudeanu 1974), p. 3 — S = {b ∈ B^n | f(b) = 0}; F : B^m → B^n is a parametric
  solution iff F(B^m) ⊆ S, general iff F(B^m) = S, reproductive iff m = n, parametric and F(s) = s for all s ∈ S.
  A general solution "is only guaranteed to yield all ground solutions"; a reproductive one is an mgu since
  any solution G is the instance G = λx.F(G(x)).
- Lemma 3.3, p. 3 — (1) is solvable iff f(0, x2..xn) ∗ f(1, x2..xn) = 0 (2) is, iff ∏_{b∈2^n} f(b) = 0 (3) holds
  in B; outside 2 "a product may well be 0 even if none of its factors are", so this is not trivial.
- Theorem 3.4 (Boole), p. 3; `unify` and Example 3.5, p. 4 — with G(y) reproductive for (2),
  F(x) = ((f(0, G(y)) + f(1, G(y)) + 1) ∗ x1 + f(0, G(y)), G(y)) (4) is reproductive for (1); base case x = ():
  succeed iff f =_B 0. The elimination order changes the number of parameters of the result (equations (5)–(7));
  Büttner (1988) chooses the order minimising them.
- Theorem 3.6 (Löwenheim) and the comparison, p. 5 — F(x) = x + f(x) ∗ (x + b) (8), + and ∗ componentwise;
  "the only 'algorithmic' aspect of this method is to find particular solutions." It "always contains as many
  parameters (new variables) as the unification problem contains variables": for x + y = 0 elimination gives
  (y, y) or (x, x), Löwenheim (x∗y, x∗y) from b = (0,0) and (x∗y + x + y, x∗y + x + y) from b = (1,1).
- §4 Theorems 4.1–4.4, Lemma 4.5, p. 5–7; §5 "Simplification", p. 7 — finite Boolean rings are finite powers
  of 2; orthogonal basis v_U = ∏_{u∈U} u ∗ ∏_{w∈C\U} (1 + w), 2^n atoms for the free ring on n generators;
  p =_B 0 iff p ∗ ∏(w_i + 1) =_E 0 under relations w_i = 0; φ : B → 2^m; t =_B 0 by rewriting or evaluation in 2.
- §6 "Finding Particular Solutions", p. 8–9 — NP-complete over 2; in polynomial form f = 0 is solvable iff f is
  not identically 1, with a solution in linear time (all 0 if 1 is absent, else a shortest monomial set to 1).
  Over B: m problems in 2 via φ, or "degenerate" Boole: if b solves f(0,y) ∗ f(1,y) = 0, (f(0,b), b) solves (1).
- §7 "Complexity", p. 9 — 0-test O(m ∗ l); Boole's eliminated term has length O(l ∗ 2^n), total O(m ∗ l ∗ 2^n),
  needing "judicious application of simplifications every time a variable is eliminated"; Löwenheim the same,
  through the particular solution; free ring on k constants: m = 2^k, O(l ∗ 2^(k+n)).
- §8 "Different Operators", p. 9–10 — 1 = 0̄, x + y = x ∗ ȳ ∪ x̄ ∗ y, x̄ = x + 1, x ∪ y = x + y + x ∗ y; translating
  problems blows up "with each translation", so translate the algorithms instead: Boole becomes
  F(x) = (f̄(1, G(y)) ∗ x1 ∪ f(0, G(y)), G(y)) (12), Löwenheim F(x) = x ∗ f̄(x) ∪ b ∗ f(x) (13); bars as in the PDF.
- §9 "Unification in the Unquantified Predicate Calculus", p. 10–12 — free Boolean ring over non-variable terms
  S; f in the orthogonal basis x_U = u1 ⋯ ur (1 + v1) ⋯ (1 + vs) (14) is equivalent to x_U = 0 for each nonzero
  coefficient (15), and x_U σ = 0 iff u_i σ = v_j σ for some i, j: unify pairs syntactically. Examples 9.1, 9.2.
- §11 "Conclusion", p. 14 — combining with other theories (Schmidt-Schauß 1988; Boudet, Jouannaud &
  Schmidt-Schauß, LICS'88) needed new methods: the axioms are "both non-regular (x + x = 0) and collapsing".
